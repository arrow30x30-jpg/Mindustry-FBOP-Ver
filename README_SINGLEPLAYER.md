# Mindustry Single-Player Version (FBOP-Ver)

This is a single-player only version of Mindustry with all multiplayer functionality removed.

## Removed Features
- Multiplayer server hosting
- Client connection to servers
- Chat functionality
- Player list
- Network synchronization
- Cross-platform multiplayer
- Steam lobbies

## Game Features Still Available
- Single-player campaign on Serpulo and Erekir
- Custom games/sandbox mode
- Map editor
- Modding support (single-player mods)
- All game mechanics and content

## Building

Requirements:
- Java 17+
- Gradle

```bash
gradlew desktop:run      # Run desktop version
gradlew android:assemble # Build Android APK
```
